# awesome-design (DESIGN.md library)

Each file in `designs/<brand>/DESIGN.md` follows Google Stitch's DESIGN.md format: YAML front matter with
`colors`, `typography`, `rounded`, `spacing`, `components`, then prose on layout, depth, motion and
do/don't rules.

## How to use it for MASRO7 LEAGUE
1. Pick 1-2 references that fit the job (index below). For the league (dark, sports/quiz, mobile app):
   `playstation`, `spotify`, `linear.app`, `revolut`, `raycast`, `nvidia`, `1win`, `apple`.
2. Read only the sections you need (`colors`, `typography`, `components`, the do/don't list).
3. Map what you borrow onto the tokens in `css/design.css` (`--bg`, `--surface`, `--brand`, `--gold`,
   `--line`, radii, shadows). Keep the league identity: blue brand + gold trophy, Arabic RTL, Readex Pro.
4. Never copy a brand's logo, name or proprietary font files; take rules and proportions only.
