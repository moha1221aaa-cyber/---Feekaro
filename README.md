# MASRO7 LEAGUE · دوري بنو مسروح للنخبة

دوري أسئلة ومعلومات عامة: مواجهات بنظام الجرس، ترتيب، توقعات للجمهور، غرفة صوتية، وبث مباشر لكل جولة بطابع برنامج مسابقات.

الموقع: https://masro7-league.pages.dev

## هيكل المشروع

```
index.html              الهيكل (HTML) بس، ويحمّل الملفات تحت بالترتيب
css/
  main.css              الشكل العام: الصفحات، الجداول، البطاقات، النوافذ، الأيقونات
  room.css              الغرفة الصوتية
  broadcast.css         بث الجولة: الاستوديو، المشاهد، الجرافيكس، الانتقالات
js/
  core.js               أيقونات SVG، وتحميل مكتبة أجورا وقت الحاجة
  pwa.js                تثبيت الموقع كتطبيق + Service Worker
  config.js             إعدادات Cloudinary و Firebase و أجورا
  voice.js              صوت الغرفة (أجورا)
  app.js                حالة التطبيق، النوافذ، المتسابقين، توليد المواجهات، التحميل والحفظ
  notifications.js      الإشعارات
  predictions.js        التوقعات (5 نقاط للنتيجة الدقيقة، 3 للفائز)
  league.js             الترتيب، ملف المتسابق، بطاقات المواجهات، التبويبات
  account.js            الحساب والدخول والتسجيل
  videos.js             التغطيات (الفيديو)
  room.js               الغرفة الصوتية: الحالة والحضور والشات
  room-tools.js         أدوات الغرفة: المؤثرات، الألعاب، بنك الأسئلة
  room-screen.js        بطاقة الغرفة وشاشتها الكاملة
  broadcast/
    engine.js           محرك البث: الحالة، وقت السيرفر، تحكم المنظم، الطيار الآلي
    presenter.js        مذيع البث
    studio.js           الاستوديو: الإحصائيات، المقدم، المخرج، التوقعات، التفاعلات
    cinema.js           المشاهد السينمائية والأصوات والموسيقى
    voice.js            صوت البث (قناة أجورا مستقلة)
    screen.js           شاشة البث: الرسم والمشاهد والانتقالات
functions/              دوال Cloudflare Pages: agora-token، tts (ElevenLabs)، time
audio/                  أصوات البث الحقيقية (mp3)
media/                  فيديو وصور الاستوديو
sw.js                   Service Worker (غيّر CACHE_NAME مع كل تحديث)
```

## ملاحظات للتعديل

- الملفات كلها سكربتات عادية (مو modules) وتشترك في نفس المتغيرات العامة، فترتيب تحميلها في `index.html` مهم: لا تنقل ملف قبل ملف يعتمد عليه.
- أي كود يشتغل لحظة التحميل (مو داخل دالة) لازم يستخدم بس أشياء معرّفة في نفس الملف أو في ملف قبله.
- النشر من مستودع Feekaro-Web-Studio عبر `league.yml`، وينسخ `css/` و `js/` تلقائياً.
- بعد أي تعديل: `node --check` لكل ملف JS، وارفع رقم `CACHE_NAME` في `sw.js`.
